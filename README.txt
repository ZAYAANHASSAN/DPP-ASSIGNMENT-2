CAREPOINT DOCTOR PORTAL — DR. ZAYAN HASSAN

Open index.html in a browser, or open this folder in VS Code and use Live Server.

Features:
- Doctor dashboard
- Appointment list with demo status updates
- Patient directory and search
- Daily schedule
- Editable doctor profile
- Responsive desktop/mobile layout

This is an academic front-end prototype. It uses sample data only, has no database or authentication, and is not connected to a real hospital. Do not enter real patient information.
